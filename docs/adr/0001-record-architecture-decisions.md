# ADR 0001: Record architecture decisions

Status: Accepted

## Context
Decisions made in conversation or code review vanish. This repository makes
every meaningful choice inspectable later.

## Decision
Every significant decision gets an ADR here, in the standard form: context,
decision, status, consequences. Numbered sequentially, never rewritten;
superseded decisions get a "Superseded by ADR NNNN" header.

## Consequences
New reviewers can reconstruct why, not just what. Prompt files, premium
factor tables, and provider selections all carry ADRs.
