# Mintmark web client

The Next.js web client of the [Mintmark](../../README.md) monorepo: dashboard,
collection gallery + table, prices, and identify. Part of the pnpm workspace; run it from
the repo root via the quickstart (`just web`, serving :3100; needs the API on :5100 for
data and renders empty states without it).
